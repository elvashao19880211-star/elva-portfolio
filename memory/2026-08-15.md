## ⚠️ git push SSH 坑（重要）
- 现象：git push 报 `Host key verification failed` → 复制 known_hosts 后又报 `Permission denied (publickey)`
- 根因：OpenClaw 把 HOME 环境变量设为 `C:\Users\Admin\.openclaw\runtime-home`，git 的 SSH 在 `runtime-home\.ssh\` 找 known_hosts 和私钥，但真实文件在 `C:\Users\Admin\.ssh\`
- 修复：把 `C:\Users\Admin\.ssh\` 下全部文件（id_ed25519 + id_ed25519.pub + known_hosts）复制到 `%HOME%\.ssh\`
- 验证：git push 显示 `main -> main` 即成功（PowerShell exit code 1 是 stderr false-positive）
